ABOUT GUANSAN

在西子湖畔，造理想的园子

观叁设计（GUANSAN DESIGN）是一家立足杭州、面向全国的高端景观设计工作室，2023 年于浙江杭州扎根。我们专注于私家别墅庭院、住宅景观与公共空间的营造，为高净值客户提供从创意设计到工程落地的一站式服务。

「观叁」之名，取「观天地人」之意——三石三竹，半池春水，一方观叁之镜。我们相信，好的庭院是自然、建筑与居住者之间的对话；设计师的工作，是让山石、草木、水光各得其所，也让生活其中的人，找到内心的秩序与安宁。

团队核心成员拥有近十年景观与建筑设计经验，曾获 ASLA 通用设计类荣誉奖、Loop Design Awards、柏林设计大奖等国内外奖项，长期服务于绿城中国等头部房企。我们以国际视野做设计，以工匠之心做落地。

DESIGN PHILOSOPHY

师法自然，
归心于院

东方造园讲究「虽由人作，宛自天开」。我们以当代的空间语言延续这一传统，在方寸之间容纳山林、水石与四季。
01 / RESPECT

尊重场地

每一块土地都有自己的记忆与肌理。我们从场地的地形、植被、光影与气候出发，让设计成为对场地的回应，而非强加。保留一棵树、一块原生石，往往比新建更有力量。

02 / NATURE

师法自然

山水自有的秩序，是设计最高的范本。我们研究自然中水岸的曲线、林木的疏密、岩石的层理，再以克制的手法转译到庭院之中，让人工之美归于天成。

03 / HABITATION

归于生活

庭院最终是为人而造。孩子的奔跑、家人的聚餐、独处时的一盏茶，都是设计的起点。我们让美学与日常共生——好看的园子，更应该是好用、好住、好相处的园子。

BUILT PROJECTS

落地案例

六个从图纸走到现场的真实庭院。我们记录下黄金时刻的光、夜间的灯，以及人在其中生活的样子——实景，是设计最诚实的表达。
01 / BUILT

和悦清晖园

HEYUE QINGHUI GARDEN
浙江 · 杭州现代自然花园已落地

在现代建筑的几何秩序之外，植入一片可游可居的自然花园。流水景墙与大草坪构成庭院的呼吸空间，树影掠过素色墙面，黄昏时分，暖色灯光从室内漫出，建筑、花园与生活在此融为一体。

流水景墙 · 树影长廊
黄金时刻 · 建筑与花园
02 / BUILT

中大吴庄

ZHONGDA WUZHUANG GARDEN
浙江 · 杭州林下日式苔庭已落地

在大树林下辟出一方静谧的苔庭。黑色砾石小径蜿蜒穿过苔藓与黑山石，竹篱围合、石灯静立，阳光从树冠筛下，在苔面上缓慢移动。时间在这里被放慢，每一步都踩在安静的绿意上。

大树之下 · 苔庭
03 / BUILT

绍兴落雁别墅

SHAOXING LUOYAN VILLA
浙江 · 绍兴自然山野别墅庭院已落地

依自然山势而建的野趣庭院。天然毛石墙与蕨类、绣球、苔藓自由生长，仿佛建筑是从这片山林中长出来的。夜里由室内望向花园，灯光温柔地勾出石墙与植物的轮廓，山居的诗意尽在这一窗之内。

天然石墙 · 山居
石墙、苔痕与绣球
04 / BUILT

萧山九章赋

XIAOSHAN JIUZHANGFU
浙江 · 杭州萧山现代住宅庭院已落地

锦鲤池、大草坪与现代住宅构成一座明亮的家庭庭院。水池中游鱼可数，草坪承接孩子的奔跑，落地玻璃把室内外连成一片。当夜幕降临，池底灯光亮起，庭院又化作另一种安静的模样。

锦鲤池 · 现代住宅
05 / BUILT

金色池塘

GOLDEN POND COURTYARD
浙江 · 杭州夜间灯光庭院已落地

一座为夜晚而设计的庭院。木塑围栏围合出私密的花园，发光踏石与灯带勾勒出步行的边界，暖色光线从植物根部漫起，照亮花境与归家的路。傍晚归家，灯火已在院中安静等候。

夜色中的庭院
灯带 · 花境
06 / BUILT

室内景观

INDOOR LANDSCAPE
浙江 · 杭州室内造景与屏风已落地

把山水意境搬进室内。天光之下，水墨竹影的玻璃屏风与片石苔藓构成室内的视觉焦点；楼梯转角的盆景、石墙与月洞窗，让原本过渡性的空间也有了驻足观赏的理由。方寸室内，亦见山林。

天光 · 竹影屏风
